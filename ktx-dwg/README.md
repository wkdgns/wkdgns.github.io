# KTX 도면 찾기

KTX 정비 중 고장 원인을 전기적으로 추적할 때 관련 전기 도면(PDF)을 빠르게 찾기 위한 개인용 오프라인 웹앱입니다.

- 도면 PDF는 사용자가 앱에서 직접 등록하며, **기기 안(브라우저 IndexedDB)에만 저장**됩니다. 이 저장소와 서버에는 도면이 올라가지 않습니다.
- 한 번 열면 서비스 워커가 앱 파일을 캐시해서 인터넷 없이 동작합니다.
- 도면 안의 글자(장치명, 회로번호, 도면번호)와 사용자가 페이지에 붙인 태그(고장 증상 등)로 검색합니다.
- 스캔본 도면은 **글자 인식(OCR)**으로 선번호·계전기 번호를 읽습니다. 사용자가 고른 도면·쪽만 인식하며, Tesseract 엔진(`ocr/`)이 기기 안에서만 실행됩니다.

## 다시 빌드하기
`source/`에서 `npm i` 후 `node build.js` → `dist/pwa/`의 파일(ocr 폴더 포함)을 이 폴더로 복사합니다.
